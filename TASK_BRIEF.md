# Краткое задание по синтезу ДОЭ

## Требования организаторов

Источники: `Хакатон_задача_q2.docx`, разделы 1–3; `AI фотоника.pdf`, слайды 2–3 и 5–6. Основные требования совпадают.

- **Задача:** нейросеть получает 4 объектных изображения и рассчитывает **один фазовый ДОЭ**, восстанавливающий каждое изображение на своей глубине.
- **Вход:** 4 PNG, каждый 128×128, grayscale, 8 бит. Порядок соответствует расстояниям ниже.
- **ДОЭ:** 128×128, фаза `φ ∈ [−π, π]`; PNG grayscale, 8 бит. Кодирование: `q = round(255·(φ+π)/(2π))`, чтение: `φ = 2π·q/255−π`. Коды 0 и 255 соответствуют −π и +π.
- **Физика:** λ = **532 нм**, шаг пиксела ПВМС = **10 мкм**; расстояния = **24,1 / 25,3 / 26,5 / 27,7 мм**.
- **Восстановление:** прямой расчёт дифракции Френеля **с одним FFT на плоскость**, как на слайде 2. Не подменять другим оператором распространения.
- **Результат:** 1 PNG ДОЭ + 4 PNG восстановлений, все 128×128, grayscale, 8 бит. Сохраняются **модули комплексного поля `|U|`**, не интенсивности `|U|²`.
- **Оценка:** Pearson и SSIM между соответствующими исходным и восстановленным изображениями. Сохранять обе метрики для каждой из 4 пар; средние — дополнительная сводка.
- **Уточнение организаторов из Telegram, сообщения 79/145/149:** каждую амплитуду нормировать по её собственному максимуму до 1; SSIM — основная метрика, Pearson — дополнительная. Усреднять по четырём плоскостям и комплектам. Учитываются время и визуальное качество; тёмная реконструкция с одной яркой точкой не является хорошим решением даже при высоком SSIM.
- **Воспроизводимость:** GitHub должен содержать код, обученные веса, Dockerfile, requirements.txt и README с готовыми командами сборки/запуска. Пользовательский дедлайн пуша — 08.11.2026 **08:00 МСК**, раньше Stop Coding организаторов.
- **Проверочные комплекты:** не менее пяти наборов по четыре изображения разных типов объектов; сохранить входы, фазовые маски, восстановления и метрики.

## Указания пользователя и рабочий подход

- Датасеты: **CIFAR10, MNIST, FashionMNIST**, уже находятся в `data/`; структура описана в `data/README.md`.
- Не использовать классический, особенно итеративный, синтез ДОЭ. Рабочий подход: один проход обученной сети непосредственно до фазы; без GS/Фиенапа, оптимизации маски на конкретном входе, развёрнутых итераций и классически рассчитанных голограмм-учителей.
- Обычное обучение общих весов сети через физический forward соответствует нейросетевой постановке; обязательное численное восстановление не является запрещённым обратным синтезом.
- Вести исследование нескольких обоснованных подходов: параллельно проверять идеи, анализировать ошибки и формулировать новые гипотезы. Автоэнкодер с физическим декодером — одна из веток, не обязательный финальный выбор. Кодстайл: `F_083 (1).ipynb`.

## Важные детали реализации

- Для стандартного single-FFT Fresnel шаг выходной сетки `Δx_z = λz/(128·Δu)`: **10,0166 / 10,5153 / 11,0141 / 11,5128 мкм**. Это следствие формулы; выходной шаг не равен 10 мкм во всех плоскостях.
- Итоговую реконструкцию считать из **сохранённой и заново прочитанной** 8-битной маски. Это проверяет фактически сдаваемый ДОЭ.
- Нормировка и агрегирование уточнены в чате. Наш актуальный `fresnel_png_v2_peak`: исходная PNG-цель / её max; амплитуда восстановления / её max → PNG → повторное чтение → метрики. Нулевое изображение остаётся нулевым; неопределённый Pearson явно отмечается. Окно SSIM и точный порядок PNG-округления организаторы не определили; используется Gaussian 11×11, sigma 1,5, valid crop. Старый `fresnel_png_v1` (фиксированный RMS/clipping) — исторический и с v2 напрямую не сравнивается.
- Сообщения 143/166 допускают физические модели внутри сети. Фиксированный линейный перенос обученных комплексных признаков можно исследовать внутри однопроходной нейросети при обязательном обучаемом синтезе финальной фазы; это не разрешение на классический синтез маски, итеративную доводку или классические фазовые метки.
- План архитектур, протокол данных и ссылки на статьи: `EXPERIMENT_PLAN.md`. Измеренные результаты, ограничения и следующие гипотезы: `EXPERIMENT_LOG.md`.
