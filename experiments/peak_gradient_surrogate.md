# Отсоединение градиента peak-нормировки: проверяемая гипотеза

## Что меняется

`src.training_normalization.peak_normalize_surrogate(raw, detach_peak=False)` сохраняет существующий forward `clip(raw / max(raw), 0, 1)`. При `detach_peak=True` максимум остаётся тем же числом, но его производная не передаётся назад. Нулевое изображение даёт нулевой результат и нулевой градиент. Обычный evaluator и сохраняемые PNG менять нельзя.

Это **смещённый training surrogate**, а не исправление ошибочной производной `amax`. Параметры по-прежнему общие веса нейросети; нет оптимизации отдельной маски, изменения физики или дополнительного inference.

## Производная

Для положительной амплитуды `a`, единственного максимума `m=a[k]`, `p=a/m` и `g=dL/dp` точная производная:

`dL/da = g/m − e[k]·sum(g·a)/m²`.

При отсоединённом максимуме остаётся `g/m`. Убирается направление в одном максимальном пикселе, которое через знаменатель одновременно меняет контраст всех остальных пикселов. В разреженной цели штраф за множество ненулевых фоновых пикселов может поощрять увеличение отдельного яркого пика: остальные пикселы после нормировки темнеют. Это возможный механизм плохой стационарной точки, не доказательство причины каждого наблюдаемого случая.

**Граница clamp задана явно.** В установленном Torch 2.14 производная `clamp(0,1)` в точках 0 и 1 равна нулю. Поэтому наивный `detach(max)` с обычным clamp дополнительно подавил бы прямой градиент максимального пиксела. В detached-режиме реализован identity-backward для clamp через `normalized + (clipped-normalized).detach()`: forward сохраняется, а для корректных неотрицательных амплитуд получается именно указанное `g/m`. Это часть явно смещённого surrogate, не скрытое свойство autograd. В обычном режиме сохранён существующий clamp.

Побочный эффект существенен: исчезают и полезные коррекции общего контраста. Forward остаётся инвариантным к положительному масштабу `a→c·a`, но detached backward уже не обязан давать нулевую производную по c. Следовательно, направление обновления не гарантирует уменьшение отображаемого normalized loss.

## Особенность физики с постоянной энергией

Для `L_MSE=mean((a/m−t)²)` detached-градиент по параметрам фазы:

`dL_MSE/dφ = −2/(N·m) · d(sum(a·t))/dφ`,

поскольку `sum(a²)` постоянно для unit-amplitude источника и унитарного Френеля с фиксированным масштабом. Квадратичный член не даёт фазового градиента. Поэтому в этой постановке detached-MSE направлен как максимизация амплитудного совпадения, то есть пропорционален градиенту cosine-loss, с зависящим от примера коэффициентом. Это не новый независимый физический критерий. Для SSIM и foreground/background-weighted MSE простое сокращение уже не действует.

## Проверка и ограничения

Пять CPU-тестов проверяют точное равенство forward обычному v2 в двух dtype, обе формулы градиента, нарушение scale-инвариантности backward при неизменном forward, тождество для фиксированной энергии и конечный нулевой градиент пустых изображений. Это проверка математики реализации, **не результат обучения**.

Предлагаемый короткий опыт: продолжение того же R46-checkpoint с прежними guards 2/0.1 и бюджетом 5k, меняется только training-gradient нормировки. Контроль — соответствующее продолжение без detached peak. Оценивать реальные PNG, Pearson, SSIM, яркость объектов и концентрацию энергии. Улучшение одного SSIM при затемнении не считать успехом; при ухудшении вернуть точную производную.
