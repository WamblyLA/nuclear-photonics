# Аудит градиентов разделения глубин

Это CPU-диагностика сохранённых checkpoint, а не новый результат обучения. Использованы первые четыре selection-четвёрки каждой группы: CIFAR10, MNIST, FashionMNIST и mixed, всего 16. Test и reserve не открывались; маски и веса не оптимизировались. Точные числа, исходные индексы, определения и SHA256 сохранены в [depth_gradient_audit.json](depth_gradient_audit.json).

У R34/R46/R49/R52 RMS различий реконструкций между плоскостями составляет 27–33% соответствующей величины целей. На этом небольшом срезе продолжение R46→R49 улучшает SSIM/Pearson, но correlation разностей между плоскостями меняется с 0,118 до 0,114. Обычный скор поэтому не заменяет проверку разделения глубин.

## Как измеряли

Для R49 `best.pt` отдельно вычислены градиенты каждой потери по фазе и по **общим параметрам сети**. Базовая потеря: MSE + (1−SSIM) + 0,5·(1−Pearson) + 2·balanced MSE + 0,1·excess concentration. Градиенты получены до clipping и AdamW; их нормы не предсказывают результат обучения.

Для смеси сначала складывались градиентные векторы групп с заданными весами, затем измерялась норма. «50% homogeneous» означает веса групп 1/6, 1/6, 1/6, 1/2; «75% homogeneous» — по 1/4. Это вероятности веток sampler: independent-ветка также иногда выбирает четыре изображения одного датасета.

| Дополнительная потеря | Норма / base, смесь 50/50 | Норма / base, смесь 75/25 |
|---|---:|---:|
| Ranking, weight 1 | 0,351 | 0,217 |
| Ranking, weight 3¹ | 1,053 | 0,651 |
| Ranking, weight 5¹ | 1,754 | 1,085 |
| Contrast MSE, weight 1 | 0,149 | 0,086 |
| High-pass depth RMS, weight 5¹ | 0,156 | 0,096 |

¹ Линейное масштабирование одного измеренного градиента, не отдельный обученный эксперимент.

Ranking = .1 выглядит очень слабым в пространстве фазы, однако Jacobian сети существенно меняет соотношение. При weight 1 его параметрический градиент достигает 80% base для mixed. Поэтому первоначальная рекомендация weight 3 после дополнительной проверки была пересмотрена: ближайший контролируемый 5k запуск — **weight 1**, margin = 0,2, с сохранением остальных настроек и отдельным продолжением-контролем из того же checkpoint.

SSIM сам по себе не даёт слабого сигнала: отношение нормы его фазового градиента к base равно 0,311 / 1,035 / 0,338 / 0,205 по четырём группам. В circular head на проверенном срезе нет попаданий в защитную область радиуса < 10⁻⁴. Это не подтверждает гипотезу о «мёртвом» phase head.

## Проверенные альтернативы

- Обычный попарный depth MSE повторяет существующий contrast MSE с множителем **8/3** для четырёх плоскостей. Считать его новой независимой идеей нельзя.
- Cosine направления попарных различий не эквивалентен MSE, но даёт нулевую потерю даже при ослаблении правильных различий до 20%. Самостоятельно он не обеспечивает достаточного разделения.
- High-pass depth RMS — проверенная на конечность градиентов гипотеза: raw amplitude и target делятся на свой RMS, из каждого пиксела вычитается среднее четырёх плоскостей, применяется `H(x)=x−avgpool5(x)` и считается MSE. Это выделяет мелкие различия без градиента через максимум изображения. Улучшение качества этим аудитом **не установлено**.

Архитектурный вывод также ограничен: residual target-ветка R48 не превзошла обычное продолжение R49; width 32 в fixed-TRAIN probe R50 переобучился. Эти результаты не доказывают, что увеличение ширины на полном train бесполезно. Решение о финальной модели данным аудитом не принималось.
