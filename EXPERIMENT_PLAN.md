# План экспериментов по нейросетевому синтезу ДОЭ

Цель — исследовать несколько способов нейросетевого синтеза и по результатам находить новые идеи. Общая постановка: **четыре изображения → обученная сеть → одна фазовая маска → фиксированное физическое восстановление**. Автоэнкодеры, глобальное смешивание и VQ — стартовые ветки, а не заранее выбранный победитель. Все варианты синтезируют ДОЭ одним проходом, без последующего поиска фазы.

Требования и константы: [TASK_BRIEF.md](TASK_BRIEF.md). Ниже — предлагаемый протокол и гипотезы, а не уже полученные результаты.

Первый цикл реализован и измерен: 15 запусков, адаптивные проверки координат, Fourier, interleave и loss, два seed и резерв исходных изображений. Фактические результаты и приоритеты следующего цикла — в [EXPERIMENT_LOG.md](EXPERIMENT_LOG.md); пункты этого плана не означают, что каждая перечисленная архитектура уже реализована.

Второй цикл также завершён: ещё 15 запусков, периодические головы фазы, synthetic-прелюдия, attention/cross-attention, ranking-loss, повтор основных вариантов на втором seed и свежий резерв. Рабочая ветка продолжения — Fourier+XY+circular с лёгким ranking; сильные контрольные варианты и ограничения сохранены в журнале. Следующие гипотезы перечислены в его конце.

## Как вести исследование

После проверки общей физики и контрольного обучения можно независимо исследовать архитектуры, представления, данные и функции потерь. Не нужно ждать завершения одной ветки для начала другой. Фактическое одновременное обучение определяет доступная память и вычислительные ресурсы; замеры скорости проводить без конкурирующих запусков.

Цикл работы: **короткие эксперименты → разбор метрик и изображений → объяснение ошибки → новые гипотезы → проверка и сочетание идей**. Удачную комбинацию можно обнаружить до доказательства пользы каждого компонента; затем нужны сравнения «база / изменение X / изменение Y / X+Y», чтобы проверить взаимодействие. Разведочные результаты не считать подтверждёнными до повторов и более полного обучения.

После каждого раунда сохранять в журнале экспериментов: гипотезу, конфигурацию и seed, split и версию evaluator, бюджет, метрики по доменам/глубинам, примеры ошибок, вывод и следующую проверку. Отрицательный результат полезен, если он сужает объяснение. Предлагаемые ниже бюджеты и очередность пересматриваются по наблюдениям; test остаётся закрытым до выбора решения.

## Почему автоэнкодер здесь уместен

Одна маска содержит 16 384 фазовых переменных, а четыре цели — 65 536 значений яркости. Точное представление произвольных независимых целей в общем случае недостижимо. Требуется научиться выбирать совместно реализуемый компромисс на распределении изображений; маска уже является физическим ограничением ёмкости.

Схема обучения:

```text
4 изображения → обучаемый энкодер и объединение признаков
              → одна фаза 128×128 → кодирование 8 бит
              → exp(iφ) → 4 фиксированных оператора Френеля
              → 4 модуля поля → ошибка относительно 4 исходных изображений
```

Фазовых меток нет. Градиент проходит через физику к общим весам сети. На новом входе веса фиксированы. Автоэнкодер с физическим декодером уже существует в литературе [1]; исследовательский вопрос проекта — какие представления лучше согласуют **четыре независимые цели** при заданных физических параметрах.

## Сначала корректная физика и оценка

Для равномерного падающего поля единичной амплитуды принять `H(u,v)=exp(iφ(u,v))`. Это рабочее предположение о подсветке.

```text
U_z(x,y) = exp(ikz)/(iλz) · exp(iπ(x²+y²)/(λz))
           · F{H(u,v) · exp(iπ(u²+v²)/(λz))}
A_z = |U_z|,  k = 2π/λ
```

В дискретной реализации учитывать множитель площади пиксела, выбранную нормировку FFT, `fftshift/ifftshift` и выходные координаты `Δx_z=λz/(NΔu)`. У каждой плоскости своя выходная сетка. Не менять N при проверке обучения: уменьшение маски меняет саму физическую задачу. Padding и ASM не включать незаметно в основной evaluator.

До обучения проверить оператор на заданных постоянной и случайной фазах: совпадение с прямой дискретной суммой на малой сетке, сохранение энергии с учётом площади пикселов, инвариантность модуля к глобальной фазе, конечные градиенты и их согласие с конечными разностями. Это проверки прямого распространения, не синтез маски под цель.

Рабочий протокол до получения официального evaluator:

- Целевой PNG трактовать как амплитуду `T=q/255`, поскольку требуется сравнение с модулем поля. Не извлекать квадратный корень без отдельного основания.
- Зафиксировать масштаб `s_z` для каждой плоскости один раз по train: согласовать средний RMS целей и RMS распространённого единичного поля. Затем одинаково для всех моделей использовать `R_z=clip(s_z·A_z,0,1)` для PNG и метрик; логировать долю клиппинга и энергию сверх диапазона. Обучающий MSE считать до clip, чтобы насыщение не скрывало ошибку и не обнуляло её градиент. Это соглашение о яркости, не условие организаторов. Персональную подгонку масштаба под val/test-цель исключить.
- Основной SSIM: Gaussian window 11×11, σ=1,5, K1=0,01, K2=0,03, `data_range=1`, population covariance, среднее по области без края шириной 5 пикселов. Дополнительно сохранять глобальный SSIM по формуле слайда 3: окно в задании не уточнено.
- Pearson считать по всем пикселам каждой пары. Для постоянной цели фиксировать «не определён» и число таких случаев; не заменять молча единицей. Постоянное предсказание при непостоянной цели отмечать как сбой модели: такой пример нельзя исключать из сравнения и тем самым улучшать среднее. В отчёте показывать долю сбоев; конфигурацию со сбоями не выбирать как победителя.
- Итог: phase PNG → чтение → восстановление → amplitude PNG → чтение → Pearson/SSIM. Float-метрики сохранять отдельно для диагностики квантования.
- Показывать результаты по каждой глубине и каждому датасету, среднее, худшую глубину и нижний дециль качества четвёрок. Время синтеза маски измерять отдельно от 4 восстановлений и файлового I/O; указывать устройство, batch=1, число параметров и память.

## Данные

Сначала разделить **исходные изображения**, затем строить четвёрки. Иначе один объект может попасть одновременно в обучение и проверку через разные комбинации.

| Датасет | Train | Validation | Test |
| --- | ---: | ---: | ---: |
| CIFAR10 | 45 000 | 5 000 | официальные 10 000 |
| MNIST | 54 000 | 6 000 | официальные 10 000 |
| FashionMNIST | 54 000 | 6 000 | официальные 10 000 |

Разделение train/validation стратифицировать по исходным классам с фиксированным seed. Классы нужны для контроля состава, не являются входом синтезатора. Все производные одного изображения остаются в одном split.

- CIFAR10: одна фиксированная формула gray `0.299R+0.587G+0.114B`. Все изображения увеличить до 128×128 одной реализацией bilinear, округлить в uint8; записать параметры преобразования. Рост разрешения не добавляет исходных деталей.
- Обучающие четвёрки собирать заново: четыре разных исходных изображения, каждое назначается своей глубине. Не закреплять класс или датасет за расстоянием.
- Основной mixed sampler: с вероятностью 1/2 брать однородную четвёрку из равновероятно выбранного датасета; иначе независимо выбирать датасет для каждой плоскости. Так контролируются и домены, и разные типы целей в одной маске.
- Зафиксировать validation-манифесты: по 512 однородных четвёрок каждого датасета и 512 смешанных. Модели сравнивать на одних ID; макросреднее считать по четырём группам с равными весами. Test использовать после выбора конфигурации.
- Отдельная диагностика: одинаковые/сходные изображения на разных глубинах, перестановка входов по глубинам, контрастные независимые цели. Коррелированные цели не подменяют основной тест.
- Позже проверить перенос: обучение на двух датасетах → третий. Это отдельный режим с собственным train-only масштабированием, а не дополнительная настройка на закрытом test.

## Архитектуры и проверяемые гипотезы

### A0 Контрольная модель

Компактный U-Net: вход 4×128×128, каналы 32/64/128, один фазовый выход `φ=π·tanh(h)`, фиксированный четырёхплоскостной декодер. Обучение без готовых голограмм. Нужен ориентир качества и проверка того, что физика, градиенты и данные согласованы [1].

### A1 Совместный автоэнкодер четырёх плоскостей

Один shared encoder применяется к каждой паре `(T_j,z_j)`. К признакам добавить embedding глубины; объединить четыре карты в фиксированном порядке расстояний и спроецировать в пространственное представление 32×32×64. Нейронный декодер выдаёт общую фазу 128×128. Не проводить обходные skip-связи мимо исследуемого латентного представления.

Гипотеза: совместное кодирование позволяет лучше распределить возможности одной маски между целями. Сначала широкий непрерывный latent; затем сравнить 32×32 и 16×16. Сильное сжатие может ухудшить результат, поскольку физическое ограничение уже есть. Сравнение с A0 оценивает весь архитектурный вариант; отдельная абляция shared encoder против конкатенации использует одинаковый decoder и latent.

### A2 Автоэнкодер с глобальным смешиванием

В A1 добавить 1–2 блока `локальная ветка + FFT признаков → обучаемое смешивание → IFFT`. Сохранить локальный путь высоких частот. Для установления вклада Fourier-блока сравнить с A1 без других изменений. Отдельно проверить координатные каналы и физические признаки `sin(π(u²+v²)/(λz_j))` и `cos(...)` на соответствующей сетке; при сравнении Fourier и локальной модели давать обеим одинаковые позиционные признаки. Разведочный запуск сочетания этих идей можно провести раньше контрольных сравнений.

Гипотеза: каждый участок голограммы влияет на всё восстановление, поэтому глобальные связи и позиционная информация полезнее одного наращивания глубины CNN. Fourier-модули для CGH уже исследовались [3]; польза именно этой адаптации проверяется отдельно. Обучаемый FFT-блок не рассчитывает маску аналитическим обратным распространением. Сравнить при близком числе параметров, а также при равном бюджете времени.

### A3 Дискретный словарь VQ

В A1 заменить непрерывный latent на ближайшие векторы обучаемого codebook: начать с 32×32 токенов, размерности 64, словаря 512 элементов. Сравнивать с непрерывным A1 при одинаковых encoder/decoder и loss; вариант словаря 1024 запускать только при признаках недостаточной ёмкости.

Гипотеза: словарь повторяемых структур облегчает кодирование допустимых решений и обобщение. Основание — Holo-VQVAE [2], но результат для четырёх плоскостей не известен. Контролировать использование словаря, collapse, потерю мелких деталей. Не смешивать VQ латента с обязательным 8-битным квантованием выходной фазы. Если VQ ухудшает качество — оставить непрерывный вариант; VAE/KL и генерация случайных сюжетов здесь не обязательны.

### A4 Представление фазы и баланс глубин

Проверять параллельно на контрольной или перспективной модели; для объяснения результата сохранить сравнения отдельных изменений:

1. `π·tanh(h)` против двух каналов `(a,b)` и `φ=atan2(b,a)`. Для второго варианта контролировать радиус около нуля, задать безопасную инициализацию и обрабатывать вырожденные выходы. В физику всегда передавать `exp(iφ)` с единичным модулем. Гипотеза — корректная периодичность фазы облегчает обучение.
2. Среднее ошибки по глубинам против среднего с небольшим штрафом за худшую глубину. Гипотеза — модель перестанет улучшать три плоскости ценой четвёртой.
3. Обучение на float-фазе против квантования фазы в forward с straight-through gradient. Реальная 8-битная маска используется в оценке всех вариантов с самого начала.

| Ветка | Короткий эксперимент | Наблюдение и следующий опыт |
| --- | --- | --- |
| Глобальные связи без сжатия | Пространственная CNN против Fourier-mixing и attention при близком бюджете; независимые и коррелированные цели | Если глобальные блоки помогают, сравнить с CNN с большим полем восприятия: отличить пользу охвата от конкретного представления |
| Координатный генератор | Encoder целей задаёт контекст; координатная сеть предсказывает `φ(u,v)` сразу во всех 128×128 точках. Все веса общие и обучены заранее | Если теряются детали — проверить частотные признаки и локальный контекст. Если ошибка возникает после PNG — проверить квантование. Сравнить с пространственным decoder |
| Несколько решений и маршрутизация | Две фазовые головы и обучаемый по входам селектор; на inference выдать одну маску без оценки кандидатов через физику | Если головы различаются, но селектор ошибается — исследовать маршрутизацию. Если головы совпадают — проверить, оправдано ли разветвление. Лучшая из голов по истинному validation-качеству допустима только как отдельно помеченная диагностика, не как итоговый результат |
| Совместимость целей и предобучение | Сравнить реальные независимые/коррелированные четвёрки и четвёрки, полученные прямым распространением случайно заданной фазы. Обучать по изображениям, без фазовых меток | Если совместимые цели проще — проверить curriculum и баланс плоскостей. Если они тоже не обучаются — проверить представление и оптимизацию. Выигрыш от такого предобучения подтвердить на реальных целях |
| Данные и функция потерь | На одной архитектуре сравнить sampler, обучение от сглаженных целей к детальным при неизменной сетке 128×128, средний и сбалансированный по глубинам loss | Если ошибка зависит от разреженности, частот или глубины — проверить адресное изменение sampling/loss и перенос на остальные домены |

Случайную фазу в диагностической ветке задаём независимо от желаемой картинки: это прямое моделирование, а не классическое решение обратной задачи. Её четыре восстановления совместимы до нормировки и квантования; для этой диагностики хранить исходные float-амплитуды и отдельно измерять искажения при преобразовании в PNG. Успех на таком распределении сам по себе не доказывает, что реальные независимые цели физически несовместимы: причиной может быть различие распределений. Следующий опыт должен различать эти объяснения.

При разборе ошибок смотреть не только средний score: отдельно оценивать фон и объект, низкие и высокие частоты, сходство целей, насыщение, глубину и чувствительность к PNG. Эти измерения помогают выбрать следующую гипотезу; они не заменяют основные метрики. Новые сочетания проверять, даже если отдельные компоненты не показали явного выигрыша, когда есть объяснение возможного взаимодействия.

## Loss и порядок запусков

Стартовая ошибка одной плоскости:

`L_j = mean((s_j·A_j−T_j)²) + 0.1·(1−SSIM_j) + 0.1·(1−Pearson_j)`.

MSE использует неклиппированную амплитуду; SSIM и Pearson — `R_j`. Так избыточная энергия в насыщенных пикселах остаётся видна обучению.

Для вырожденных по дисперсии целей Pearson-компоненту пропускать явно; при обучении стабилизировать знаменатель корреляции малым epsilon. Общая ошибка сначала `mean_j L_j`; отдельная абляция добавляет `0.1·max_j L_j`. Коэффициенты — стартовые гиперпараметры, затем небольшой поиск на validation. VQ добавляет codebook/commitment losses. Perceptual loss и TV фазы по умолчанию не нужны: первый может ухудшать SSIM [2], вторая может подавлять полезную структуру голограммы.

| Очередь | Запуск | Бюджет и решение |
| --- | --- | --- |
| 0 | Физический оператор, PNG, метрики, splits | Переходить к обучению после проверок численной корректности |
| 1 | A0 на MNIST, четыре независимые цели | 1 000 обновлений, batch 16; проверить снижение train/val ошибки и отсутствие вырождения. При провале разобраться с протоколом, не расширять архитектурный поиск |
| 2 | Первый разведочный раунд: A0 и 2–4 различающиеся ветки из списка | По 1 000–5 000 обновлений, batch 16, одинаковые tuples/seed, AdamW с начальным lr 2e−4. Выбирать не только похожие варианты AE; фиксировать кривые и время |
| 3 | Разбор ошибок и следующий раунд | Продолжить перспективные ветки, проверить альтернативные объяснения и открыть новые. Удачные сочетания разложить на контрольные сравнения; короткий неудачный запуск ещё не опровергает метод |
| 4 | Подтверждение двух перспективных вариантов | До 20 000 обновлений каждый, 3 seed; проверить устойчивость выигрыша. Новые независимые разведочные ветки могут идти одновременно с подтверждением |
| 5 | Данные и перенос | Mixed против однородного обучения; затем leave-one-dataset-out и финальный закрытый test |

Это ограничение числа обновлений, не обещание времени: доступный GPU и скорость нужно измерить на первом запуске. При нехватке памяти одинаково уменьшить batch для сравниваемых моделей. Полную сетку всех комбинаций не запускать.

Критерий выбора: улучшение validation SSIM при сопоставимом Pearson и без провала отдельной глубины/домена. Сохранять Pareto-набор, если метрики расходятся; официального единого score в задании нет. Для финалистов показывать разброс по seed и парные различия на фиксированных четвёрках. При близком качестве предпочитать более быстрый и простой вариант. Все сравнения — после одинакового PNG round-trip.

## Статьи и границы переноса

1. **Wu et al., 2021 — [High-speed computer-generated holography using an autoencoder-based deep neural network](https://opg.optica.org/ol/abstract.cfm?uri=ol-46-12-2908)**, DOI 10.1364/OL.425485. Физическое распространение в декодере и обучение фазовых голограмм без парных фазовых меток. Обосновывает основу; не доказывает качество нашей четырёхплоскостной постановки.
2. **Park, Kang, 2024 — [Holo-VQVAE, arXiv v1](https://arxiv.org/html/2404.01330v1)**. Изображение → VQ latent → фазовый decoder → ASM → loss изображения. В этой версии есть MNIST/FashionMNIST 64×64 и CelebA-HQ 128×128. VQ сравнивается с Gaussian VAE, а не доказывается превосходство над любым непрерывным AE. У нас заменить ASM требуемым Fresnel и проверить четыре плоскости. PixelSnail для генерации новых сюжетов не использовать. Не смешивать результаты этой версии с журнальной P-Hologen.
3. **Dong et al., 2023 — [Fourier-inspired neural module for real-time and high-fidelity computer-generated holography](https://opg.optica.org/ol/abstract.cfm?uri=ol-48-3-759)**, DOI 10.1364/OL.477630. Fourier-модуль улучшал исследованные U-Net/HoloNet; мотивирует глобальные признаки. Приведённые авторами скорости и метрики не являются прогнозом для наших параметров.
4. **Eybposh et al., 2020 — [DeepCGH](https://doi.org/10.1364/OE.399624)**; [код авторов](https://github.com/UNC-optics/DeepCGH). Нейросетевой многоплоскостной синтез с обучением через оптическую модель; полезна идея interleaving/pixel-unshuffle. Оригинальный переход из предсказанного комплексного поля к SLM включает аналитическое обратное преобразование; готовый pipeline не переносим при нашем запрете классического синтеза.

Новизна предлагаемой комбинации — рабочая гипотеза проекта, не заявление о мировом первенстве. Заимствуемые идеи проверяются абляциями. GS/Фиенап, per-input оптимизация, unrolling, классические фазовые учителя, обратный аналитический синтез и итеративный sampling исключены из плана.
