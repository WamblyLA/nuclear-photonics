# Презентация для пяти минут защиты

[Редактируемая презентация PowerPoint](solution.pptx) содержит восемь слайдов, заметки докладчика, три таблицы и диаграмму с вложенной таблицей данных. [PDF](solution.pdf) — статическая копия для просмотра: страницы отрисованы изображениями, текст в PDF не выделяется. Ссылки на ветку и README на последней странице активны в обоих форматах.

[Заметки докладчика](speaker_notes.md) рассчитаны на 300 секунд и содержат ссылки на источники. [Происхождение данных](presentation_provenance.json) фиксирует модель R72, SHA-256 весов, архивы оценок и их контрольные суммы. [Проверка поставки](presentation_validation.json) описывает структурную проверку и просмотр всех восьми страниц.

Selection, reserve и официальные test-выборки CIFAR10/MNIST/FashionMNIST показаны отдельно. Эти test-выборки не являются скрытым тестом организаторов. Демонстрация использует заранее зафиксированный `input_set1`; межплоскостные помехи видны и не скрыты. Физическая граница относится к сумме L1-ошибок двух нормированных интенсивностей, а не к SSIM.

Слайды созданы локально с помощью среды подготовки презентаций Codex. Закрытые зависимости этой среды не нужны для открытия или редактирования PPTX и не входят в зависимости обучения и запуска модели. Публичная поставка не обещает автономного запуска локального генератора слайдов.
